# 回帰確認チェックリスト

コードを変更して新しいパッケージをインストールしたら、この一覧で「開ける・使える／閉じられる・再起動後も状態が残る・クラッシュしない」ことを確認します。全項目には約 45～60 分かかります。特定のモジュールだけを変更した場合も、最低限 **A：基本確認** と該当モジュールの項目を実施してください。手順は Android を基準にしていますが、iOS にも適用できます（ログは `Documents/LinkuraOffline/server.log` を参照）。

## 0. 準備

1. 端末を操作する前にプレイヤーDBをバックアップします。
   - Android：`adb exec-out run-as com.oddno.lovelive cat files/HasuKikaisann.sqlite3 > backup.sqlite3`
   - iOS：`xcrun devicectl device copy from ... --source "Library/Application Support/LinkuraOffline/HasuKikaisann.sqlite3"`
2. 新しいパッケージを上書きインストールします（Android は `adb install -r`、iOS は `tools/ios_device_setup.py`）。アンインストールやデータ消去はしないでください。
3. 機内モードを有効にし、オフラインでも動くことを確認します。

各項目の合格条件は、画面が想定どおりであり、ログに `FATAL EXCEPTION`、`Fatal signal`、新しい `no mock file or registered route`（iOS では `no route for`）がないことです。

既知の無害な未登録 API：`/v1/activity_record/notify_month_displayed`（通知のみ）。

## 終了時

1. 未登録 API とクラッシュの記録を再集計します（第 0 節を参照）。
2. 前後のプレイヤーDBを比較し、所持、ダイヤ、ポイント、編成が操作内容に合うことと、`PRAGMA integrity_check` が ok であることを確認します。
3. スクリーンショット番号、ログファイル名、APK SHA-256、localify のコミットを当日の検証記録に残します。
