# 已知限制

离线版依赖停服前保存下来的资源缓存。缓存里没有的东西无法恢复；以一份较完整的缓存为例，最终资源清单 54,503 个文件中约 40,500 个可用，缺约 13.7 GB，集中在剧情和视频。用 `tools/resources/hailstorm.py coverage` 查看你自己的缓存。

| 项目 | 现状 | 原因 |
|---|---|---|
| 活動記録的剧情播放 | 再生确认后弹窗关闭，不播放 | 剧情配音和大部分 3D 场景、动作没有保存。剧本文本（`story_main_*.txt`）通常完整，可以用 `hailstorm.py decrypt` 查看 |
| SHOW 歌词 MV | 选项固定关闭（iOS 打包参数 `--disable-lyric-videos`） | MV 视频基本没有保存 |
| Chapter RANK | 顶栏显示 SS，点击提示「Chapter対象期間外です」 | Chapter 页面资源从未保存；最后一个 Chapter 按主数据于 2026-06-30 结束 |
| With×STATION、Fes×Live 存档 | 列表为空 | 视频没有保存 |
| お知らせ | 空白 | 公告由服务器下发，没有保存 |
| キャッシュ削除、登出、删除用户 | 无效 | 离线下会清掉无法再下载的资源或本地身份 |
| SIsCa 弹窗数字 | 末位被截断 | 原版界面宽度限制 |
| プレイPt. | 最多 999 | 顶栏只为 3 位数留了宽度；客户端会拦截超出的回复 |
| SHOW | 0 分也显示 LIVE CLEAR；部分角色技能发动时没有语音 | 原版客户端行为：没有失败状态；技能语音不叠加，带「除外」技能的卡每局只发动一次 |
| 画面 | 游戏默认分辨率和字体 | 原 linkura-localify 的渲染设置和字体替换已移除 |
| 玩家 ID | 固定为 000000000 | 离线只有一个本地存档。资源包只带资源目录库和新生成的存储密钥，不含原账号的 ID 和密钥 |
