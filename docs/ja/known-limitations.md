# 既知の制限

オフライン版はサービス終了前に保存したアセットキャッシュに依存します。保存されなかったアセットは復元できません。比較的充実したキャッシュの例では、最終カタログの 54,503 ファイルのうち約 40,500 ファイルが利用可能で、主にストーリーと動画の約 13.7 GB が不足しています。ご自身のキャッシュは `tools/resources/hailstorm.py coverage` で確認してください。

| 項目 | 現状 | 理由 |
|---|---|---|
| 活動記録のストーリー再生 | 再生確認後、ダイアログを閉じて再生しません | ボイスと大部分の 3D シーン・モーションが保存されていません。脚本テキスト（`story_main_*.txt`）は通常そろっており、`hailstorm.py decrypt` で確認できます。 |
| SHOW の歌詞 MV | オプションをオフに固定します（iOS のパッケージ化オプション `--disable-lyric-videos`） | MV 動画はほとんど保存されていません。 |
| Chapter RANK | 上部に SS と表示し、タップすると「Chapter対象期間外です」を表示します | Chapter 画面のアセットは保存されていません。マスターデータ上、最後の Chapter は 2026 年 6 月 30 日に終了しました。 |
| スクールアイドルコネクトのアーカイブ | ARCHIVES に 16 件のアーカイブをそれぞれのサムネイル付きで表示します（サムネイルは `assets/` に置きます）。タップしても反応しません（パッケージ作成オプション `--allow-archive-playback` で戻せます）。With×STATION の一覧は空です | 再生に必要な 3D ステージ・衣装・タイムラインのアセットと動画が保存されておらず、公式 CDN は 404 を返します。公式 CDN はほとんどのサムネイルも削除しています。 |
| お知らせ | 空白です | お知らせはサーバーから配信され、保存されていません。 |
| キャッシュ削除、ログアウト、ユーザー削除 | 無効です | オフラインでは再ダウンロードできないアセットやローカルの身元情報が消えてしまいます。 |
| SIsCa のダイアログ数字 | 最後の一桁が切れます | 元の画面幅による制限です。 |
| プレイPt. | 最大 999 です | 上部表示は三桁分だけの幅です。クライアントはそれを超えるレスポンス値を拒否します。 |
| SHOW | 0 点でも LIVE CLEAR と表示され、一部のキャラクタースキルにボイスがありません | 元のクライアントの動作です。失敗状態がなく、スキルボイスは重ならず、「除外」スキルを持つカードは一回のプレイで一度だけ発動します。 |
| 画面 | ゲーム既定の解像度とフォントです | 元の linkura-localify の描画設定とフォント置き換えを削除しました。 |
| プレイヤー ID | 000000000 に固定します | オフラインではローカルセーブが一つだけです。リソースパックにはカタログDB、マスターデータDB、新しいストレージキーだけを含み、元アカウントの ID とキーは含みません。 |
| Grade | Grade 1・0 Pt から始まり、Grade Pt は Grade Quest の報酬だけで増えます。シーズングレードと順位は 0 です | Live Grand Prix の Grade Pt はランキング報酬で、Grade Challenge とシーズングレードは終了済みの期間で集計されます。オフラインには他のプレイヤーもその期間もありません |
| Live Grand Prix | マスターデータの 69 回を順番に開催し、各回は元の日数で進みます（日付は 4:00 JST に切り替わります）。Pt はスコア × ステージランクボーナス × カードボーナス（レアリティと解放段階をデッキ平均）です。順位は Pt からのシミュレーションで、終了時に元の順位区分で報酬を配ります。サークル対抗戦は個人戦のルールで行い、キャラクターボーナスは適用しません。初回クリアなどのステージ報酬は利用できず、SHOW の Grand Prix は未実装です | 元の Pt 計算はサーバー側にあり保存されていません。順位は他のプレイヤーに依存します。シーズンファンLvとステージ報酬テーブルは保存されていません |
| ショップ | アイテム交換所、GP PRIZE交換所、セレクトチケット交換所（チケットとカードの交換はショップのみ。ガチャ画面には表示しません）、ステッカー交換所、SIsCaストア（SIsCa でアイテムを購入）、解放Pt.変換を利用できます。SIsCa の購入はできません。所持済みのカードを再び獲得すると、そのカードの解放素材になります。999 を超えるアイテム所持数（SIsCa、Grade Pt.、スタイルPt.、ペタルコインを除く）は初回起動時に 999 にし、GP PRIZE交換チケットは上限の 9999 まで補充します。ステッカー交換所のステッカーはセーブですべて所持済みのため、交換できるものはありません。解放Pt.変換は解放段階を最大まで上げた後に余る素材だけを変換し、ティアは最大 9999 です | SIsCa の購入には App Store の課金が必要です。交換ポップアップの所持数は 3 桁分の幅しかありません。ティアの所持上限は 9999（Items.LimitNum）です |
| ログインボーナス | 提供しません。ホームからログインボーナス画面を開かず、ログインボーナスも配りません | 元のログインボーナスのレスポンスは保存されていません。クライアントのデータモデルから再構成した版では、iOS のログインボーナス画面が Now Loading のまま止まりました |
