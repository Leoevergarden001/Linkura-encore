# 已知限制

离线版依赖停服前保存下来的资源缓存。缓存里没有的东西无法恢复；以一份较完整的缓存为例，最终资源清单 54,503 个文件中约 40,500 个可用，缺约 13.7 GB，集中在剧情和视频。用 `tools/resources/hailstorm.py coverage` 查看你自己的缓存。

| 项目 | 现状 | 原因 |
|---|---|---|
| 活動記録的剧情播放 | 再生确认后弹窗关闭，不播放 | 剧情配音和大部分 3D 场景、动作没有保存。剧本文本（`story_main_*.txt`）通常完整，可以用 `hailstorm.py decrypt` 查看 |
| SHOW 歌词 MV | 选项固定关闭（iOS 打包参数 `--disable-lyric-videos`） | MV 视频基本没有保存 |
| Chapter RANK | 顶栏显示 SS，点击提示「Chapter対象期間外です」 | Chapter 页面资源从未保存；最后一个 Chapter 按主数据于 2026-06-30 结束 |
| With×STATION、Fes×Live 存档 | 列表为空 | 视频没有保存 |
| お知らせ | 空白 | 公告由服务器下发，没有保存 |
| キャッシュ削除、登出、删除用户 | 无效 | 离线下会清掉无法再下载的资源或本地身份 |
| SIsCa 弹窗数字 | 末位被截断 | 原版界面宽度限制 |
| プレイPt. | 最多 999 | 顶栏只为 3 位数留了宽度；客户端会拦截超出的回复 |
| SHOW | 0 分也显示 LIVE CLEAR；部分角色技能发动时没有语音 | 原版客户端行为：没有失败状态；技能语音不叠加，带「除外」技能的卡每局只发动一次 |
| 画面 | 游戏默认分辨率和字体 | 原 linkura-localify 的渲染设置和字体替换已移除 |
| 玩家 ID | 固定为 000000000 | 离线只有一个本地存档。资源包只带资源目录库、主数据库和新生成的存储密钥，不含原账号的 ID 和密钥 |
| Grade | 从 Grade 1、0 Pt 开始，只有 Grade Quest 奖励会增加 Grade Pt；季度 Grade 和排名为 0 | Live Grand Prix 的 Grade Pt 是排名奖励，Grade Challenge 和季度 Grade 按已结束的期间计算，离线没有其他玩家和这些期间 |
| Live Grand Prix | 按游戏数据的 69 场依次开放，每场按原版天数计时（凌晨 4 点换日）；Pt = 分数 × 舞台等级加成 × 卡牌加成（稀有度和解放段数，取编队平均）；排名是按 Pt 模拟的，结束时按原版名次区间发奖励；サークル对抗战按个人战规则进行；角色加成不计；首次通关等舞台奖励不可用；SHOW 的 Grand Prix 未实现 | 原版计分公式在服务器上，没有保存；排名依赖其他玩家；季度ファンLv和舞台奖励表没有保存 |
| 商店 | アイテム交換所、GP PRIZE交換所、セレクトチケット交換所（在扭蛋画面用券换卡）、ステッカー交換所、SIsCaストア（用 SIsCa 买道具）和解放Pt.変換可用；SIsCa 充值不可用；已持有的卡再次获得时变成这张卡的解放素材；道具持有量超过 999 的（SIsCa、Grade Pt.、スタイルPt.、ペタルコイン除外）首次启动时降到 999；解放Pt.変換只转换卡牌升满解放后多出的素材，ティア最多 9999 | 充值需要 App Store 内购；兑换弹窗的持有数只为 3 位数留了宽度；ティア的持有上限是 9999（Items.LimitNum） |
| 登录奖励 | 每天第一次进入首页时显示常规登录奖励（定常ログインボーナス，7 天一轮：前 6 天各 50 SIsCa，第 7 天 100）；活动登录奖励不显示 | 原版的登录奖励响应没有保存，按客户端的数据结构重建；活动登录奖励都有原版期限，离线没有对应的期间 |
