# 回归检查清单

每次修改代码并装上新包后，按本清单回归。目标是用同样的步骤确认"能打开、能用或能退出、重启后状态保留、不崩溃"。全部做完约 45–60 分钟；只改了某个模块时，至少做 **A 基线** 加上对应模块的条目。清单按 Android 写成，iOS 同样适用（日志看 `Documents/LinkuraOffline/server.log`）。

## 0. 准备

1. 备份玩家库后再动设备：
   - Android：`adb exec-out run-as com.oddno.lovelive cat files/HasuKikaisann.sqlite3 > backup.sqlite3`
   - iOS：`xcrun devicectl device copy from ... --source "Library/Application Support/LinkuraOffline/HasuKikaisann.sqlite3"`
2. 覆盖安装新包（Android `adb install -r`，iOS `tools/ios_device_setup.py`），不要卸载或清除数据。
3. 开启飞行模式，确认离线下也能运行。

每一项通过的标准：画面符合预期，日志中没有 `FATAL EXCEPTION`、`Fatal signal`，也没有新的 `no mock file or registered route`（iOS 为 `no route for`）。

已知无害的未匹配接口：`/v1/activity_record/notify_month_displayed`（通知类）。
