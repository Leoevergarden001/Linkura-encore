# linkura-offline

「Link！Like！ラブライブ！蓮ノ空スクールアイドルクラブ」（リンクラ）の**非公式**オフライン実行プロジェクトです。公式サーバーのサービス終了後も、手元にあるクライアントとアセットキャッシュを使ってオフラインで遊び続けられるようにし、今後の開発や修正の基盤を提供します。

## 主な機能

元のクライアントが端末内のオフラインサービスに接続し、保存済みのゲームアセットを読み込みます。タイトル画面の LOGIN からローカルのゲーム状態に入ります。公式サーバーへの接続や、以前のアカウントの復元は行いません。Android と iOS は同じオフラインサーバーとプレイヤー状態の処理を使用します。

- **Home と日常操作**：Home に入り、カード、ミッション、プロフィール、コレクション、復旧したメニューやショップの入口を利用できます。一部の入口は空の状態や保護のための案内のみを表示します。詳細は下記の既知の制限をご覧ください。
- **SHOW とスクステ**：SHOW（リズムゲーム）に入り、結果画面まで進めます。また、スクールアイドルステージ（スクステ）の Daily Live、Quest Live、Learning Live、Grade Live、Dream Live、Live Grand Prix などをプレイできます。表示できる楽曲、画面、演出は手元のアセットキャッシュによって異なります。
- **ガチャとカード**：実装済みのローカルなガチャからカードを引き、履歴やポイントを確認できます。カード育成、編成、アイテム交換も利用できます。ガチャのラインナップや確率は、公式サービスの全履歴を再現したものではありません。
- **ローカルの進行状況**：ガチャ結果、所持カード、編成、ステージ結果などを端末内の SQLite データベースに保存し、再起動後も引き継ぎます。オフラインのプレイヤー ID は `000000000` 固定で、以前の公式アカウントとは別です。
- **アセットの整理と移行**：キャッシュの網羅率確認、Android 用リソースパックの作成と導入、利用可能な Android キャッシュの iOS 向け変換ができます。変換によって保存されていないコンテンツを復元することはできません。

これらの機能にはクライアントのバージョンに合うキャッシュが必要です。アセットの不足によって利用できないコンテンツもあります。

## 対応クライアント

| プラットフォーム | 現在の対応バージョン | インストール方法 |
|---|---|---|
| Android | 5.1.0 | LSPatch でオフラインモジュールを APK に組み込みます。インストール先の端末に root 権限や別のモジュール管理アプリは不要です |
| iOS / iPadOS | 5.0.1 | オフライン用コンポーネントとパッチを IPA に組み込み、ご自身の Apple 署名でインストールします。脱獄は不要です |

現在、上記のクライアントを対象にビルドと検証を行っています。iOS の静的パッチは元のバイト列を照合するため、他のバージョンやビルドにはそのまま適用できません。両プラットフォームともアセットのバージョンを合わせる必要があります。詳しくは[対応バージョン](docs/ja/getting-started.md)をご覧ください。

## 用意するもの

本リポジトリにはコード、ビルドツール、オフラインサービス用データが含まれます。元のゲームの APK、IPA、完全なアセットキャッシュ、アカウント情報は含まれません。リポジトリをクローンするだけではプレイ可能なクライアントにはなりません。

1. **クライアント**：Android 5.1.0 の APK、または復号済みの iOS 5.0.1 の IPA。通常の暗号化された App Store の IPA は、現在の iOS パッチ手順にそのまま使用できません。
2. **アセット**：ご自身の端末に保存された `D/` のキャッシュ、`M/` 内のカタログ DB とマスターデータ DB、および両方のデータベースに対応するストレージキー。アセットファイルだけでは、新しい端末へのインストールを完了できません。[アセットの準備](docs/ja/resources.md)をご覧ください。
3. **パソコンと端末**：Android のインストールには ADB が必要です。iOS のインストールには、Mac と Xcode のツール、信頼済みで開発者モードを有効にした端末、その端末を含むプロビジョニングプロファイルが必要です。ソースからビルドする場合は、対応する SDK、コンパイラ、Python の依存パッケージも必要です。詳しくは[はじめに](docs/ja/getting-started.md)をご覧ください。

アセットキャッシュは十数 GB 以上になる場合があり、パックの作成や端末への転送には中間ファイル用の空き容量も必要です。リソースパックや端末のバックアップには個人情報が含まれる場合があります。元のアーカイブを残し、端末を変更する前に既存の進行状況をバックアップしてください。パック作成ツールは、標準ではカタログ DB とマスターデータ DB に新しいキーを生成し、元のアカウントの `app` データベースを含めません。

## インストール方法を選ぶ

どちらの方法でも本リポジトリのインストールツールを使用します。まだコードを取得していない場合は、次を実行してください。

```sh
git clone --recurse-submodules https://github.com/LeoEvergarden/Linkura-offline.git
cd Linkura-offline
```

### オフライン版のインストールパッケージとリソースパックがある場合

- **Android**：対応するオフライン APK と Android 用リソースパックを用意し、ファイルの SHA-256 を確認します。パックが `.tar.zst` の場合は、中身を確認して新しいディレクトリに展開してください。インストールツールの `--pack` には、`files/D/`、`files/M/`、`files/linkura-local/storage-key.json` を含む**ディレクトリ**を指定します。圧縮ファイルを直接指定することはできません。公式版や署名の異なるアプリが既にある場合は、データをバックアップしてください。署名の異なる APK は上書きインストールできません。[Android のインストール](docs/ja/android.md)をご覧ください。
- **iOS / iPadOS**：未署名のオフライン IPA と `container/` を含むアセットのディレクトリを用意します。[iOS のインストール手順](docs/ja/ios.md)に従い、ご自身の署名でインストールしてアセットを転送してください。対象端末向けに署名済みの IPA がある場合は、インストールスクリプトの `--ipa` を使用します（引数は `python3 tools/ios_device_setup.py --help` を参照）。無料の開発用署名は通常、定期的な更新が必要です。

準備済みのパッケージがあればクライアントのビルドは省けますが、バージョンの確認とアセットの転送は必要です。未署名の iOS IPA には署名も必要です。リソースパックだけでは APK や IPA の代わりになりません。

### 手元のクライアントとキャッシュからビルドする場合

[はじめに・対応バージョン](docs/ja/getting-started.md)で入力を確認し、[Android のビルドとインストール](docs/ja/android.md)または[iOS のビルドとインストール](docs/ja/ios.md)に進んでください。キャッシュの取り出し、キーの再生成、Android から iOS への変換については[アセットの準備](docs/ja/resources.md)をご覧ください。入力に応じて手順を選ぶ[エージェント向けセットアップ Skill](.agents/skills/linkura-offline-setup/SKILL.md)もありますが、クライアント、アセット、端末はご自身で用意する必要があります。

## インストール後の確認

1. 端末をオフラインにするか機内モードを有効にします。ゲームをコールドスタートし、タイトル画面で LOGIN を押して Home に入れることを確認します。
2. キャッシュに保存済みの SHOW の楽曲またはスクステのステージを開き、開始・結果表示・復帰ができることを確認します。
3. ローカルの状態が変わる操作を行い、再起動後も結果が残ることを確認します。キャッシュ削除、ログアウト、ユーザー削除を確認方法に使わないでください。
4. ダウンロードエラー、画面の空白、開けないページがある場合は、下記の既知の制限と[回帰確認チェックリスト](docs/ja/regression-checklist.md)、各プラットフォームのログを確認してください。

これらの確認で分かるのは、試した手順がそのキャッシュで動くことだけです。すべての楽曲、ステージ、アセットが揃っていることまでは保証しません。

## 既知の制限

オフライン版は、終了した公式 CDN から不足しているアセットをダウンロードできません。保存されていないストーリーボイス、歌詞 MV、アーカイブ動画は再生できません。お知らせ、ソーシャル機能、Chapter の一部の画面は空の状態や案内だけを表示します。再ダウンロードできないアセットを保護するため、キャッシュ削除、ログアウト、ユーザー削除の操作は無効にしています。詳しい範囲と理由は[既知の制限](docs/ja/known-limitations.md)をご覧ください。

## プロジェクト構成と開発

| ディレクトリ | 用途 |
|---|---|
| `server/` | Android と iOS で共通のオフライン API、レスポンステンプレート、ローカルのプレイヤー状態 |
| `android/` | Android の Hook、LSPatch モジュール、クライアント側のオフライン修正 |
| `ios/` | iOS のオフライン用コンポーネント。クライアントの静的パッチとパッケージ化ツールは `tools/` にあります |
| `tools/` | クライアントのパッケージ化、端末へのインストール、アセット処理、解析ツール |

開発を続ける場合は、[全体構成](docs/ja/architecture.md)、[オフラインサーバー](docs/ja/server.md)、[Android Hook](docs/ja/hooking-android.md)、[iOS パッチ](docs/ja/patching-ios.md)から始めてください。変更後は[回帰確認チェックリスト](docs/ja/regression-checklist.md)で確認し、用語は[用語集](docs/glossary.md)を参照してください。

```sh
server/build-host.sh && python3 server/tests/smoke_test.py
python3 -m unittest discover -s tools/tests -t .
python3 -m unittest discover -s server/generators/tests
```

最後のコマンドには PyYAML が必要です。これらのコマンドはホスト版オフラインサーバー、ツール、データ生成器を確認しますが、実機やエミュレーターでの回帰確認の代わりにはなりません。
